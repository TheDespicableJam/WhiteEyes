# WhiteEyes
WhiteEyes is a chilling ARG made for Boba Bash X 3AM
It Follows the story of the cult WhiteEyes. <br>
This is a part of a bigger ARG I will be making.

# How To Play
### Runnning Locally
1. Clone the repo<br>
2. Open the first Index.html file in your browser and play from that points on

### Play online
Go onto [WhiteEyes](https://thedespicablejam.github.io/WhiteEyes/) to play.<br>


# Tech Stack and Design

## Design
The site uses a dark background along with white text to really sell the idea of a "creepy" vibe. <br>
Along with that instead of going with the classic horror trope to jumpscare I went with slowly revealed horror with rarely any jumpscares <br>
The site also uses CSS animations for glitch effects and page wide color inversions to really go with the spooky theme

## Tech Stack
This site works like old "pick an option" kind of games, where you play by choosing on of the given options.<br>
So to get a basic idea of this version I used the vanilla web dev tech stack
<ul>
<li>HTML</li>
<li>JavaScript</li>
<li>CSS</li>
</ul>
