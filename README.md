# WhiteEyes
WhiteEyes is a chilling ARG made for Boba Bash X 3AM
This is a part of a bigger ARG I will be making.
It Follows the story of the cult WhiteEyes

# How To Play
Go onto [WhiteEyes](https://thedespicablejam.github.io/WhiteEyes/) to play. <br>
This site works like old "pick an option" kind of games, where you play by choosing from an option given.

# Tech Stack
WhiteEyes is an ARG style website made using the vanilla web dev tech stack, HTML, JavaScript and Vanilla CSS.
